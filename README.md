# CSS Course

Lessons and assignments from my CSS course, organized by week.

## Structure
- `Lessons/Week_1` to `Lessons/Week_8`: lesson code
- `Assignment For Lessons/`: tasks for each section, each with an `index.html` and `css/master.css`

## Run
Open any `index.html` in the browser.
